# Proč se mi to děje?

- Projekt obsahující krátké e-knihy, zamýšlející se nad různými okolnostmi,
  životními situacemi a jejich vzájemným ovlivňováním.

## Struktura projektu

### /epub

- Složka obsahuje poslední verze jednotlivých e-knih ve formátu epub.

### /markdown

- Toto je zdrojová složka, ve které dochází k úpravám a odkud jsou
  generována aktuální verze e-knih.

### /pdf

- Složka obsahuje poslední verze jednotlivých e-knih ve formátu pdf.

### /sablony

- Složka se definicí šablon pro copier.
